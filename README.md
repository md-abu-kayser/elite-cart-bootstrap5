## Overview

EliteCart is a premium, responsive storefront concept designed to feel like a modern luxury commerce brand. It includes rich product discovery, promotional banners, theme customization, dynamic cart behavior, wishlist controls, search suggestions, and highly polished product presentation.

This project is ideal for showcasing how a boutique online store can combine elegant visual design with functional e-commerce interactions using only HTML, CSS, and JavaScript.

---

## Why This Project Stands Out

- Premium brand identity with luxury-inspired color themes
- Fully responsive shopping layout for desktop, tablet, and mobile
- Conversion-focused UX with product cards, promotions, and deal sections
- Interactive cart and wishlist functionality with persistent browser storage
- Theme switching and dark mode support for a modern user experience
- Search and filtering logic for smoother product discovery
- Clean, scalable frontend architecture suitable for extension

---

## Features

### Storefront Experience

- Premium header and announcement bar with rotating promotional messaging
- Sticky navigation with category dropdown and mega menu layout
- Live search suggestions and product filtering
- Hero banner with promotional call-to-action buttons
- Deal-of-the-day section with pricing emphasis and urgency cues
- Product grid with ratings, badges, pricing, and quick actions

### Shopping Interactions

- Add-to-cart functionality with live badge updates
- Wishlist toggle with persistent user state
- Cart drawer with item quantity controls and total pricing
- Quick view modal for product previews
- Product sorting and category filtering
- Search-driven discovery across product listings

### UX Enhancements

- Multiple luxury theme palettes
- Toggleable dark mode
- Loading preloader for premium first impression
- Animated transitions using AOS and polished CSS effects
- Toast notifications for cart and wishlist interactions

## Getting Started

### 1) Clone the Repository

```bash
git clone https://github.com/md-abu-kayser/elite-cart-bootstrap5.git
cd elite-cart-bootstrap5
```

### 2) Run the Project

You can either open `index.html` directly in the browser, or launch a local web server for a cleaner experience:

#### Option A: Simple Local Server

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000
```

#### Option B: Using Node.js

```bash
npx serve
```

## Customization

This project is structured for easy modification.

- Update product data in `js/script.js`
- Adjust branding, layout, or spacing in `css/styles.css`
- Edit storefront structure and content in `index.html`
- Swap color themes by changing theme variables and theme buttons
